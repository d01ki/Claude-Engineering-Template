# Release readiness

1. Verify release scope, changelog, dependencies, and migration steps.
2. Check required tests, scanners, documentation and rollback plan.
3. Confirm release artifact provenance and secrets handling.
4. Identify compatibility and operational risks.
5. Provide a go/no-go checklist with explicit remaining blockers.
6. Ask approval before tags, publishing, deployments, migrations, or spending.
